# CV fonts

The unmodified Nunito regular, bold, italic and bold-italic faces and Raleway bold face were recovered from the embedded font resources in Sirui's original public Google Docs CV export on October 23, 2026. Retaining these faces preserves the established PDF typography. No proprietary Arial face was copied into this directory.

The bundled font files are distributed under the SIL Open Font License 1.1; see [Nunito license](OFL-Nunito.txt) and [Raleway license](OFL-Raleway.txt).

License sources, checked October 23, 2026:

- [Google Fonts Nunito](https://github.com/google/fonts/tree/main/ofl/nunito)
- [Google Fonts Raleway](https://github.com/google/fonts/tree/main/ofl/raleway)

The font copyright names in the recovered TTF metadata agree with those sources. Fonts are embedded as subsets in the generated PDF. This directory is a source dependency and is excluded from the public Jekyll projection.
